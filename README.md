Sistema de Gerenciamento de Empréstimos com Automação de Cobranças

Projeto desenvolvido para simular um sistema bancário utilizando
MySQL e n8n.

O sistema permite o gerenciamento de clientes, empréstimos,
parcelas e pagamentos e possui uma automação responsável por
identificar parcelas em atraso e enviar notificações aos clientes.

-Tecnologias

- MySQL
- MySQL Workbench
- n8n
- SQL


-Funcionalidades

- Cadastro para os clientes
- cadastro de emprestimos
- Cadastro de empréstimos
- Controle de parcelas
- Registro de pagamentos
- Identificação de parcelas em atraso
- Envio automático de notificações
- Registro das notificações enviadas
